# ChapterBox

Turn long YouTube lectures into bite-sized chapter videos.

[Live Demo](https://punit-65.github.io/chapterbox/) · [Report Bug](https://github.com/Punit-65/chapterbox/issues) · [Request Feature](https://github.com/Punit-65/chapterbox/issues)

## What is ChapterBox?

ChapterBox is a browser-based tool that splits long YouTube lectures (or entire playlists) into proper chapter videos. Every chapter plays like its own short video. Your progress, notes, and study plan are saved locally in the browser.

### Features

- Split long lectures into individual chapter videos
- Add full playlists in one click
- Study planner (set finish date or daily minutes)
- Notes with clickable timestamps + revise list
- Goals, streaks & simple smart coach
- Everything stays in your browser (no account needed)

## How to Use

1. Open [https://punit-65.github.io/chapterbox/](https://punit-65.github.io/chapterbox/)
2. Click **+ Add a video** or **Add a playlist**
3. Paste a YouTube link
4. Start studying chapter by chapter

## Tech Stack

- Pure HTML, CSS & JavaScript (no framework)
- Hosted on GitHub Pages

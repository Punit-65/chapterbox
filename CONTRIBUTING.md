# Contributing to ChapterBox

Thanks for your interest in contributing!

## How to contribute

1. Open an issue first if you're planning a big change
2. Fork the repo and create a new branch
3. Make your changes
4. Open a Pull Request with a clear description

## What kind of contributions are needed?

- Bug fixes
- UI/UX improvements
- Better mobile experience
- Handling videos without chapters
- Export/import of notes & progress
- Documentation improvements
